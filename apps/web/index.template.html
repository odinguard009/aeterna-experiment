Controls
Tap a card to open its actions; tap a zone (Trash, Soul State, Burst) to look inside it. Long-press a card to zoom it. On a PC hover a card to read it. Keyboard: Space or Enter = Next step, L = game log, Esc = close.

    Card data (JSON)

    Load your own card list. Only Spirit and Nexus cards work in this build. Imported cards have no coded effect, so their text is shown for reference only.

    Card images

    Pick image files from your own device. A file is matched to a card by (1) the image field in your card data, so any file name works, (2) the card ID (for example BS76-001.png), or (3) the exact card name. Images stay in this browser only and are never uploaded.

    Deck list (text)

    One card per line: 3 BS44-001 or 3x Card Name. Lines starting with # are ignored.
